The logouts came from saving settings, and that's now fixed. All 12 tests pass: the 10 existing ones plus 2 new ones.

**Cause:** `persistSettings` in `src/settings/service.js` called `req.session.regenerate()` before writing the settings. Regenerating creates a new, empty session, so `userId` was lost and the next request returned 401. It looked random because it only hit users who saved their settings.

**Fix:** `persistSettings` now writes the settings onto the existing session and saves it, with no regenerate. I removed the regenerate instead of copying `userId` across, because changing the session id mid-session can also log a user out when another request is in flight. Nothing under `src/auth/` was touched.

**Test:** the new `tests/settings.test.js` logs in, saves settings, then checks that `/me` and `/notes` still return 200. It failed against the old code and passes now.

**Not fixed — in `src/auth/`:** `login` in `src/auth/login.js` doesn't regenerate the session, and that is the place where it belongs, to prevent session fixation. If you add it there, set `userId` after the regenerate.

Nothing is committed.
